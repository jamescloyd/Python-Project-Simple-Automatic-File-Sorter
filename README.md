# Python Project: Simple Automatic File Sorter

In this project, I created a simple automatic file sorter to move the .csv, .txt, .png, and .tsv files in the original folder to their respective folder. For example, the file sorter moves all the .txt files to a folder called "Text Files" and all the .csv files to a folder called "CSV Files", etc.

First, Python checks if the new folders already exist. If not, it creates them. Then, Python checks if the files to be sorted already exist in the folder where we want them to be. If not, it moves them to their respective folder.

Here, I practiced using the os and shutil modules, for loops, and if statements to create this automatic file sorter. Please see the Python file in this repository for more detail.
